Experimental 64-bit engine

Runs freestanding ELF64 programs using a subset of x86-64 instructions. Arch Linux and ISO boot are not supported yet. Firmware, paging, interrupts, and PC devices are still needed.

Up to 8 GiB of sparse address space; up to 128 MiB of written pages. The demo accesses memory above 4 GiB. This is separate from the v86 VM settings.

Download demo ELF

ELF uploads stay in this browser. Maximum file size: 16 MiB. Supported host calls: write to stdout/stderr and exit. General Linux applications require additional instructions and system calls.

VirtualBox Browser edition

A browser VM manager using VirtualBox’s original icons and a familiar desktop layout. Guest instructions run locally in the v86 WebAssembly emulator.

This is an alternative browser frontend and execution engine, not a compiled port of Oracle VirtualBox. The original Qt GUI and VirtualBox hypervisor do not run here.

  • Supported: compatible 16/32-bit x86 guests, VGA display, keyboard/mouse, local ISO/floppy/raw/standalone VDI media, saved states, snapshots, disk export.
  • Unavailable: 64-bit guests, multicore, VT-x/AMD-V, VirtualBox Guest Additions, USB/PCI passthrough, native bridged/NAT networking, VirtualBox saved states, OVA/OVF, VMDK, and 3D acceleration.
  • Performance and guest compatibility depend on v86. No guest internet access is configured. Guest media is never uploaded.
  • Disk writes are persisted on Power Off, Save State, and snapshots. Closing the tab can lose recent writes; explicitly save before leaving.

Engine: v86 0.5.470 (BSD-2-Clause). BIOS: SeaBIOS / VGA BIOS from its pinned upstream revision. See the frontend README for source and license information.
